# COMPLIT: THE OPERATIVE SYSTEM (Project Manifesto)

## 1. VISION & CORE PHILOSOPHY
Complit is not a To-Do list. It is a **Gamified Life Operating System (OS)** with a Cyberpunk/Ingress-inspired aesthetic.
The User is not a "user"; they are the **MAINFRAME / OPERATOR**.
The goal is to fight **ENTROPY** (Procrastination/Decay) and maintain **SYSTEM STABILITY** (Mental Health) while charging **NODES** (Goals).

## 2. DOMAIN LANGUAGE (The Lore)

| Traditional Term | Complit Term | Description |
| :--- | :--- | :--- |
| **User** | **Mainframe / OS** | The central entity. It has a Version (v1.0) that upgrades when Nodes are completed. |
| **Goal / Project** | **NODE** | A finite objective to be charged (0% to 100%). E.g., "Trip to Japan", "Launch App". |
| **Skill / Area** | **SUBSYSTEM** | Persistent stats linked to Nodes. E.g., "Finance Module", "Japanese Language Module". They suffer decay if unused. |
| **Habit / Task** | **PROTOCOL** | Actionable items. Executing them generates energy or stability. |
| **Mental Health** | **STABILITY (HP)** | A daily finite resource (0-100%). Low stability causes UI glitches. |
| **XP / Progress** | **CHARGE** | Energy generated by Protocols to upgrade Subsystems and Nodes. |
| **Laziness** | **ENTROPY / RUST** | The force that degrades Subsystems and Nodes over time. |

## 3. GAME MECHANICS (The Logic)

### A. The Energy Flow Loop
1. **Input:** Operator executes a **PROTOCOL** (e.g., "Duolingo Session").
2. **Cost:** It consumes **STABILITY** (Mental Energy) OR restores it (if it's a Maintenance Protocol like Sleeping).
3. **Output:** It generates **CHARGE**.
4. **Distribution:**
   - Charge flows into the linked **SUBSYSTEM** (e.g., "Language Module" gains XP).
   - If the Subsystem is connected to a **NODE** (e.g., "Japan Trip"), the Node's progress bar increases.

### B. The Entropy System (Decay)
- **Daily Cron Job:** Every 24h at 00:00.
- **Effect:** Subsystems that received no Charge lose a small percentage of XP (Rust).
- **Visuals:** Neglected Subsystems look "rusty" or "glitched" in the UI.

### C. The Mainframe (User)
- Starts as `v1.0`.
- Completing a **NODE** (reaching 100%) triggers a "System Upgrade" -> `v1.1`.
- Visual reward: New themes/skins (Bronze -> Silver -> Neon).

## 4. TECH STACK & ARCHITECTURE

- **Repo:** Monorepo.
- **Frontend:** React + TanStack Router.
- **UI Library:** Custom components heavily inspired (Sci-Fi/Cyberpunk) and **React Flow** (for the Node Graph visualization).
- **Backend:** fastify.js API.
- **Database:** PostgreSQL.
- **Auth:** Google OAuth (Session Cookies).
